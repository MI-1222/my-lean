## 問題構成と概要

### 【第1問】三角形と四面体に関する不等式(ヴァイツェンベックの不等式)

- **配点**: 60点
- **分野**: 図形と計量、初等幾何、不等式
- **問題概要**:
  - (1) $h > 0$ とする。平面上の原点 $\mathrm{O}(0, 0)$、点 $\mathrm{P}(h, s)$、点 $\mathrm{Q}(h, t)$ ($s < t$) に対して、$\triangle\mathrm{OPQ}$ の面積を $S$、辺の長さを $p = \mathrm{OP}, q = \mathrm{OQ}, r = \mathrm{PQ}$ とするとき、不等式
    $$ p^2 + q^2 + r^2 \ge 4\sqrt{3} S $$
    が成り立つことを示せ。また等号成立条件となる $s, t$ を求めよ。
  - (2) 四面体 $\mathrm{ABCD}$ の表面積を $T$、各辺の長さを $a, b, c, l, m, n$ とするとき、不等式
    $$ a^2 + b^2 + c^2 + l^2 + m^2 + n^2 \ge 2\sqrt{3} T $$
    が成り立つことを示せ。また等号成立条件を求めよ。
- **解答・方針**:
  - (1) $p^2 = h^2 + s^2, q^2 = h^2 + t^2, r^2 = (t - s)^2$ および $S = \frac{1}{2} h (t - s)$ を代入して差をとると、
    $$ p^2 + q^2 + r^2 - 4\sqrt{3} S = 2\left(h - \frac{\sqrt{3}}{2}(t - s)\right)^2 + \frac{1}{2}(t + s)^2 \ge 0 $$
    と平方完成できる。平方の和であるため常に非負である。等号成立は $t + s = 0$ かつ $h = \frac{\sqrt{3}}{2}(t - s)$、すなわち $s = -\frac{h}{\sqrt{3}}, t = \frac{h}{\sqrt{3}}$ のときであり、$\triangle\mathrm{OPQ}$ が正三角形となるときである。
  - (2) 四面体の4つの三角形の面それぞれに (1) の不等式(ヴァイツェンベックの不等式)を適用する。4つの不等式を加算すると、各辺長は2つの面に共有されるため左辺は各辺の2乗和の2倍、右辺は $4\sqrt{3} T$ となる。両辺を2で割ることで所要の不等式が得られる。等号成立は4面すべてが正三角形、すなわち正四面体のときである。

### 【第2問】積分方程式と連続関数の決定

- **配点**: 60点
- **分野**: 微積分、積分方程式、連続関数
- **問題概要**:
  $1 \le x \le 2$ で次の等式を満たす連続関数 $f(x)$ と定数 $A, B$ を求めよ。
  $$ \int_{1/x}^{2/x} |\log y| f(xy) \, \mathrm{d}y = 3x(\log x - 1) + A + \frac{B}{x} $$
- **解答・方針**:
  変数変換 $z = xy$ により、左辺は $\frac{1}{x} \int_1^2 |\log z - \log x| f(z) \, \mathrm{d}z$ となる。
  両辺に $x$ を掛けて絶対値を $z \le x$ と $z \ge x$ で外すと、
  $$ \int_1^x (\log x - \log z) f(z) \, \mathrm{d}z + \int_x^2 (\log z - \log x) f(z) \, \mathrm{d}z = 3x^2 (\log x - 1) + Ax + B $$
  両辺を $x$ で微分すると $\log x f(x)$ の項が相殺され、
  $$ \frac{1}{x}\left(\int_1^x f(z) \, \mathrm{d}z - \int_x^2 f(z) \, \mathrm{d}z\right) = 6x \log x - 3x + A $$
  を得る。$x = 1, 2$ を代入することで $A = 5 - 8\log 2$ を特定する。
  さらに両辺を微分して $f(x) = 6x \log x + \frac{5}{2} - 4\log 2$ を決定し、元の等式に値を代入して $B = 4(\log 2)^2 + 5\log 2$ を導出する。

### 【第3問】複素数平面と格子点の計数

- **配点**: 60点
- **分野**: 複素数平面、整数、格子点
- **問題概要**:
  $i$ を虚数単位とする。実部と虚部がともに整数である複素数 $z$ により $\frac{z}{3+2i}$ と表される複素数の集合を $M$ とする。
  - (1) 原点を中心とする半径 $r$ の円内(境界含む)にある $M$ の要素数を $N(r)$ とするとき、$10 \le N(r) \le 25$ を満たす $r$ の範囲を求めよ。
  - (2) 6本の線分で囲まれたL字型の領域に含まれる $M$ の要素数を求めよ。
- **解答・方針**:
  $z = p + qi$ ($p, q \in \mathbb{Z}$) とおく。$|3+2i|^2 = 13$ より、$w = \frac{z}{3+2i} \in M$ のノルムは $|w|^2 = \frac{p^2 + q^2}{13}$ である。
  - (1) $|w| \le r \iff p^2 + q^2 \le 13r^2$。整数の2乗和 $p^2 + q^2$ の値と対応する格子点数から、$N(r)$ が 10 以上 25 以下となる条件は $4 \le 13r^2 \le 8$ であり、$\frac{2}{\sqrt{13}} \le r \le \frac{2\sqrt{2}}{\sqrt{13}}$ となる。
  - (2) 線分で囲まれた領域 $D$ は、単位正方形 $[0, 1] \times [0, 1]$ から右上 $[1/2, 1] \times [1/2, 1]$ を除いた領域である。変換 $z = (3+2i)w$ により対応するガウス平面上の多角形領域内の格子点を数えると、合計 12 個存在する。

### 【第4問】平面による空間分割の最大数

- **配点**: 60点
- **分野**: 空間図形、離散数学、漸化式
- **問題概要**:
  $H_1, \dots, H_n$ を空間内の相異なる $n$ 枚の平面とする。これらの平面によって分割される空間領域の数を $T(H_1, \dots, H_n)$ とする。
  - (1) $T(H_1, \dots, H_n)$ のとりうる最大値を求めよ。
  - (2) $n \ge 2$ のとき、とりうる値のうち2番目に大きいものを求めよ。
  - (3) $n \ge 3$ のとき、とりうる値のうち3番目に大きいものを求めよ。
- **解答・方針**:
  - (1) 2次元において $k$ 本の直線による平面分割の最大数は $S(k) = \binom{k}{0} + \binom{k}{1} + \binom{k}{2} = \frac{k^2+k+2}{2}$ である。
  3次元空間において一般の位置にある $n$ 枚目の平面を追加すると、既存の $n-1$ 枚の平面との交線により $S(n-1)$ 個の領域が増加する。
  したがって漸化式 $T(n) = T(n-1) + S(n-1)$ を解くことで、最大値は
  $$ T_{\max}(n) = \binom{n}{0} + \binom{n}{1} + \binom{n}{2} + \binom{n}{3} = \frac{n^3 + 5n + 6}{6} $$
  となる。
  - (2) $n \ge 2$ のとき、平面分割の減少量は $n$ 枚目の平面上にできる交線の平行性(または3直線の1点共有)により最小で 1 減少し、$T_n^{(\mathrm{2nd})} = T_n^{(\mathrm{max})} - 1 = \frac{n^3 + 5n}{6}$ となる。
  - (3) $n \ge 3$ のとき、交線の減少を2箇所生じさせることで通常は最大値より 2 減少した値 $T_n^{(\mathrm{3rd})} = T_n^{(\mathrm{max})} - 2 = \frac{n^3 + 5n - 6}{6}$ をとりうる。ただし $n = 4$ のときのみ幾何学的配置の制約から 13 の値を取り得ず、3番目に大きい値は例外的に $12$ となる。

### 【第5問】関数の単調性と数列の最大値

- **配点**: 60点
- **分野**: 微分法、数列の極限・最大値
- **問題概要**:
  $a = \frac{256}{81}$、数列 $b_k = \frac{(k+1)^{k+1}}{a^k k!}$ ($k \ge 1$) とする。
  - (1) 関数 $f(x) = (x+1)\log\left(1 + \frac{1}{x}\right)$ は $x > 0$ で減少することを示せ。
  - (2) 数列 $\{b_k\}$ の最大値 $M$ を既約分数で表し、$b_k = M$ となる $k$ をすべて求めよ。
- **解答・方針**:
  - (1) 1階導関数 $f'(x) = \log\left(1 + \frac{1}{x}\right) - \frac{1}{x}$、2階導関数 $f''(x) = \frac{1}{x^2(x+1)} > 0$ より、$f'(x)$ は狭義単調増加である。$\lim_{x \to \infty} f'(x) = 0$ であるため、すべての $x > 0$ で $f'(x) < 0$ となり、$f(x)$ は減少する。
  - (2) 隣接項の比は $\frac{b_k}{b_{k-1}} = \frac{1}{a}\left(1 + \frac{1}{k}\right)^{k+1} = \frac{1}{a} \exp(f(k))$ であり、$k$ の増加に伴い単調減少する。
    $b_1 = \frac{81}{64}, \frac{b_2}{b_1} = \frac{2187}{2048} > 1, \frac{b_3}{b_2} = 1, \frac{b_4}{b_3} < 1$ となるため、
    最大値は $M = b_2 = b_3 = \frac{3^{11}}{2^{17}} = \frac{177147}{131072}$ であり、$k = 2, 3$ である。
