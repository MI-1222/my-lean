## 問題構成と概要

### 【第1問】1次式の平方和に関する等式(文理共通・文系第3問)

- **配点**: 30点
- **分野**: 多項式、代数
- **問題概要**:
  1次式 $A(x), B(x), C(x)$ に対して $\{A(x)\}^2 + \{B(x)\}^2 = \{C(x)\}^2$ が成り立つとする。このとき $A(x)$ と $B(x)$ はともに $C(x)$ の定数倍であることを示せ。
- **解答・方針**:
  恒等式を変形して $\{C(x) - A(x)\}\{C(x) + A(x)\} = \{B(x)\}^2$ とする。
  あるいは複素数範囲で因数分解して $\{C(x) - i B(x)\}\{C(x) + i B(x)\} = \{A(x)\}^2$ と考える。
  $C(x) = 0$ となる根 $\alpha$ を代入すると $A(\alpha)^2 + B(\alpha)^2 = 0$ となり、実数値であることから $A(\alpha) = B(\alpha) = 0$ を得る。
  $A(x), B(x), C(x)$ はすべて 1次式であり共通の根 $\alpha$ を持つため、互いに定数倍の関係となる。

### 【第2問】確率行列と数列の収束

- **配点**: 35点
- **分野**: 行列、数列の極限
- **問題概要**:
  $a$ を実数として、行列 $A = \begin{pmatrix} a & 1-a \\ 1-a & a \end{pmatrix}$ と定める。
  $\begin{pmatrix} x_0 \\ y_0 \end{pmatrix} = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$ とし、
  $\begin{pmatrix} x_n \\ y_n \end{pmatrix} = A \begin{pmatrix} x_{n-1} \\ y_{n-1} \end{pmatrix}$ ($n=1,2,\dots$)
  で数列 $\{x_n\}, \{y_n\}$ を定めるとき、$\{x_n\}$ が収束するための $a$ の必要十分条件を求めよ。
- **解答・方針**:
  固有値・固有ベクトルの分解、あるいは $x_n + y_n = 1$ および $x_n - y_n = (2a - 1)(x_{n-1} - y_{n-1})$ を利用する。
  $x_n - y_n = (2a - 1)^n$ より、一般項は $x_n = \frac{1 + (2a - 1)^n}{2}$ と求まる。
  数列 $\{x_n\}$ が収束するための必要十分条件は等比数列 $(2a - 1)^n$ が収束することであり、
  $-1 < 2a - 1 \le 1 \iff 0 < a \le 1$
  となる。

### 【第3問】さいころの出目の和の確率(文系第1問類題)

- **配点**: 35点
- **分野**: 確率、場合の数(重複組合せ)
- **問題概要**:
  さいころを $n$ 個同時に投げるとき、出た目の数の和が $n+3$ になる確率を求めよ。
- **解答・方針**:
  各さいころの目を $X_i \in \{1, 2, 3, 4, 5, 6\}$ とし、$Y_i = X_i - 1$ とおく。
  条件は $Y_i \ge 0$ かつ $\sum_{i=1}^n Y_i = 3$ である。
  和が $3$ であるため、各 $Y_i$ が $5$ を超えることはなく、非負整数解の個数は重複組合せ $_n\mathrm{H}_3 = \binom{n+3-1}{3} = \binom{n+2}{3} = \frac{n(n+1)(n+2)}{6}$ に等しい。
  全体の場合の数は $6^n$ 通りであるから、求める確率は
  $P = \frac{\binom{n+2}{3}}{6^n} = \frac{n(n+1)(n+2)}{6^{n+1}}$
  である。

### 【第4問】外接円と内接円の半径の不等式

- **配点**: 35点
- **分野**: 図形と計量、初等幾何・三角不等式
- **問題概要**:
  平面上の点 $\mathrm{O}$ を中心とし半径 $1$ の円周上に相異なる3点 $\mathrm{A}, \mathrm{B}, \mathrm{C}$ がある。$\triangle\mathrm{ABC}$ の内接円の半径 $r$ は $1/2$ 以下であることを示せ。
- **解答・方針**:
  オイラーの定理(Euler's triangle formula)によれば、外心 $\mathrm{O}$ と内心 $\mathrm{I}$ の間の距離 $d = \mathrm{OI}$ に対して
  $d^2 = R(R - 2r)$
  が成立する。$R = 1$ かつ $d^2 \ge 0$ より $1 - 2r \ge 0$、すなわち $r \le 1/2$ を得る。
  等号成立は $d = 0$、すなわち外心と内心が一致する正三角形の場合である。

### 【第5問】回転体容器からの排水と微分方程式

- **配点**: 35点
- **分野**: 数学III(微積分、体積と積分方程式)
- **問題概要**:
  原点 $\mathrm{O}$ と点 $\mathrm{P}(R, 0, H)$ を結ぶ線分を $z$ 軸まわりに回転させてできる円錐容器に水を満たし、
  水面の高さが $h$ のとき単位時間あたりの排水量が $\sqrt{h}$ となるように排水する。
  すべての水を排出するのに要する時間を求めよ。
- **解答・方針**:
  高さ $h$ における水平断面の半径は $\frac{R}{H} h$ であるから、水平断面積は $S(h) = \pi \left(\frac{R}{H} h\right)^2 = \frac{\pi R^2}{H^2} h^2$。
  微小時間 $\mathrm{d}t$ の間に排出される水量は $\mathrm{d}V = S(h) (-\mathrm{d}h) = \sqrt{h} \mathrm{d}t$。
  したがって $\mathrm{d}t = -\frac{\pi R^2}{H^2} h^{3/2} \mathrm{d}h$。
  $h = H$ から $h = 0$ までの所要時間 $T$ は定積分
  $T = \int_0^H \frac{\pi R^2}{H^2} h^{3/2} \mathrm{d}h = \frac{\pi R^2}{H^2} \left[ \frac{2}{5} h^{5/2} \right]_0^H = \frac{2}{5} \pi R^2 \sqrt{H}$
  となる。

### 【第6問】tan 1° の無理数性(文理共通・文系第5問)

- **配点**: 30点
- **分野**: 三角関数、背理法
- **問題概要**:
  $\tan 1^{\circ}$ は有理数か。
- **解答・方針**:
  有理数と仮定すると、正接の加法定理の反復適用により $\tan 60^{\circ} = \sqrt{3}$ も有理数となり矛盾する。
  ゆえに $\tan 1^{\circ}$ は有理数ではない(無理数である)。
