## 問題概要
$\tan 1^{\circ}$ は有理数か。

## 解答・証明方針
$\tan 1^{\circ}$ が有理数であると仮定して矛盾を導く(背理法)。
1. 正接の加法定理 $\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$ により、有理数同士の和角の正接は有理数となる。
2. $\tan 1^{\circ}$ の有理数性から、加法定理を順次適用することで以下がすべて有理数となる：
   - $1^{\circ} + 1^{\circ} = 2^{\circ}$
   - $2^{\circ} + 1^{\circ} = 3^{\circ}$
   - $3^{\circ} + 3^{\circ} = 6^{\circ}$
   - $6^{\circ} + 6^{\circ} = 12^{\circ}$
   - $12^{\circ} + 12^{\circ} = 24^{\circ}$
   - $24^{\circ} + 6^{\circ} = 30^{\circ}$
   - $30^{\circ} + 30^{\circ} = 60^{\circ}$
3. したがって $\tan 60^{\circ}$ も有理数となる。
4. しかし、$\tan 60^{\circ} = \tan(\pi / 3) = \sqrt{3}$ であり、$\sqrt{3}$ は無理数であるため矛盾する。
5. ゆえに、$\tan 1^{\circ}$ は有理数ではない(無理数である)。
